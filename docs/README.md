# Screenshots for the README

These are the shots the main [README](../README.md) embeds. All four are in use —
if you replace one, keep the filename so the README keeps working.

| file | what it shows | where it appears |
|---|---|---|
| `dashboard.png` | the sidebar with the report list and a report open | top of the README |
| `analysis.png` | the 分析 / 导入 panel (① 下载 + 分析 / ② 导入已分析 SGF) | 快速开始 · Quickstart |

Grab them straight from the running app at ~1400px wide or more. Retina screenshots
are fine — GitHub scales them down, and the `width="90%"` in the README does the rest.

A shot is a claim about the current UI, so re-take one when you change what it shows.
`report.png` in particular is the only place the trend-chart legend is on display.
